# 新闻日报

游戏 · AI · 财经 · 时政与全球大事，每日早报 09:00 / 晚报 18:00 自动生成并发布。

- 在线地址：https://Jweeeeee.github.io/news-daily-brief/
- `index.html`：手机优先的历史浏览页面（日期条 / 归档抽屉 / 期号下拉 / 日期跳转）
- `data/manifest.json`：期号清单
- `data/<日期>-<morning|evening>.json`：每期正文

每期由本地 DSH 定时任务生成，先写本地站点数据，再同步推送到本仓库 main 分支，GitHub Pages 自动发布。
